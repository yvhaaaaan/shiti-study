# 打铁匠

Vue 3 + TypeScript + uni-app 错题学习工具，支持响应式 H5 与微信小程序源码。围绕「先进入错题库，再按科目进入错题本，最后按知识点巩固」组织文字、题图、解析、笔记和复习记录。

## 本地运行

使用 Node.js 20 或更新版本，在项目根目录执行：

```sh
npm ci
npm run dev:h5
```

浏览器打开 `http://127.0.0.1:5173/`，页面自动适配电脑与手机宽度。

```sh
npm run build:static
```

H5 产物位于 `dist/build/h5/`，同时复制至 `dist/client/`；单独构建 H5 使用 `npm run build:h5`。

## 两种运行方式

- **本地模式**：H5 使用 IndexedDB，首次运行提供示例数据；小程序使用本机存储。不同浏览器与设备的本地档案相互独立。
- **服务器模式**：Go + SQLite 后端提供账号登录、题库、独立题图存储和备份。同一账号跨设备刷新读取最新档案；编辑发生版本冲突时拒绝覆盖，保留当前修改。

部署与服务管理见 [服务器版说明](server/vps/README.md)。配置与运行数据独立于源码，API 密钥只设置在服务端环境变量中。

## 收录与整理

- **错题库与错题本分离**：错题库负责跨学科收录和批量管理；我的错题本按科目聚合，科目内部使用一个主知识点和少量相关知识点。旧标签只作为兼容元数据保留，新流程不要求维护大量标签。

- 首页提供文字录入、拍照／上传和批量录题。单题先保存题干与题图为「待整理」，分类与解析可稍后补充；保存不等待 OCR 或 AI。
- H5 支持选图、拖图和粘贴截图。接受 PNG、JPEG、WebP，原文件每张最多 20 MiB，处理后不超过 2 MiB；每题最多 3 张。拖图与粘贴只添加图片，不自动识别或调用模型。
- 批量录入支持最多 10 张独立题图，或将一张整页照片拆成最多 20 道题。整页识别通过 SSE 逐题显示，可边识别边修改，后续结果保留修改；勾选核对后保存，失败重试保留题目 ID。
- 整理可手动完成，或显式使用 AI 生成分类、标签、答案与解析。H5 流式展示结果，仍须核对后保存；失败保留原题，不自动反复调用。
- 服务器支持配置 DeepSeek 或 MiMo，未配置时显示提示；MiMo 适配见 [接入文档](docs/MiMo接入.md)。浏览器本地 OCR 为可选操作，使用自托管 Tesseract.js，不消耗模型额度；小程序暂不支持本地 OCR。
- 支持预设／自定义科目与自由标签，每题最多 30 个标签、每个最多 32 字。完成整理需选择科目与难度，答案可稍后补充。已移除独立错因字段，旧档案仍可读取。

## 我的错题与学习流程

- 「我的错题本」默认按科目展示书架，翻开后只看该科错题；「全部题目」保留跨科搜索与批量管理。首页提供直接翻本与今日练习入口。
- 每题新增「我的复盘」：当时为什么错、我现在的理解、下次提醒自己；每项最多 2000 字，与原作答、参考解析和备注分开保存。
- 理解进展按五阶练习记录：识错、重做、讲透、迁移、隔天回验。每阶有独立任务与动画，迁移需补充变式题和核对依据，第五阶至少隔一个自然日；完成后保留整页记录。采用学生对照依据自评，旧掌握标记不伪造为五阶成果。详见 [错题本与五阶锻造](docs/错题本与五阶锻造.md)。

- 卡片展示题干和题图，可切换紧凑列表；支持整理状态、科目、标签、掌握状态和难度筛选，条件可逐项撤销。
- 搜索覆盖题目、答案、原作答、解析、来源、标签与备注。待整理题目先打开档案，再通过「继续整理」编辑；保存后保留筛选位置。
- 「我的答案」为选填项，单题与批量录入均可填写，在题目档案中独立展示；每次复习的作答单独记录，不覆盖录入时的答案。
- H5 题干、答案、解析、笔记与预览使用本地 KaTeX 排版公式，支持行内与独立公式、分数、根式、上下标和矩阵。编辑时保留原始文字，带公式的内容提供预览；长公式可在自身区域横向查看。小程序目前采用可读文本降级，Word 导出保留公式原文，尚未生成 Word 原生公式。
- 批量管理区分本页与全部筛选结果，支持合并标签、删除和恢复；整批校验、一次保存，失败可重试。
- 每题补充说明支持文字与最多 6 张备注附图，和原题图片分别管理；知识笔记支持图片与关联题目。
- 支持复习排期、独立重做、掌握情况记录、学习报告、组卷和 DOCX 导出。重做需要参考答案，待整理题目不进入复习和组卷；Word 可含文字、PNG／JPEG 题图及答案解析附录。

## 备份与恢复

可导出个人资料、题目、笔记、练习卷和复习历史，预览后恢复 JSON；恢复替换整份档案，不自动合并。服务器完整导出包含图片数据，支持迁移。

清理本地浏览器或小程序数据会影响档案，应另行备份。微信本地题图路径仅在原设备有效，JSON 不自动打包这些本地文件，跨设备恢复前会提示限制。

## 微信小程序

```sh
npm run build:mp-weixin
```

用微信开发者工具导入本项目或 `dist/build/mp-weixin/`。根目录 `project.config.json` 已指向构建目录；持续开发使用 `npm run dev:mp-weixin`，导入 `dist/dev/mp-weixin/`。

`touristappid` 用于本地工程检查。正式发布需自己的 AppID、HTTPS 合法域名、接口和登录配置。代码可构建，尚未完成微信真机验证，拍照、预览和容量仍需实机检查。

## 检查与图标

```sh
npm run typecheck
npm run verify:forge
node scripts/verify-export.cjs
npm run build:static
npm run build:mp-weixin
```

导出验证样本写入忽略目录 `.validation/`。Go 后端在 `server/vps/` 内运行 `go test ./...`。

图标采用工坊配色的原创双色插画与 Lucide 圆角线条；H5 加载本地 SVG，小程序使用内置矢量数据。Lucide ISC 许可位于 `src/static/icons/LUCIDE-LICENSE.txt`。修改 `scripts/expressive-icons.cjs` 或 `scripts/generate-icons.cjs` 后，运行 `node scripts/generate-icons.cjs` 更新图标。产品标识为原创锤与砧图形。
