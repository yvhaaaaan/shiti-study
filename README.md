# 拾题

Vue 3 + TypeScript + uni-app，实现同一套代码的响应式网页版与微信小程序。围绕错题收录、解题解析、独立复习、知识笔记与组卷导出组织学习流程。

## 运行网页版

使用 Node.js 20 或更新版本，在项目目录执行：

```sh
npm install
npm run dev:h5 -- --host 127.0.0.1
```

浏览器打开 `http://127.0.0.1:5173`。桌面与手机宽度使用同一页面自动适配。

```sh
npm run build:h5
```

生成的静态文件位于 `dist/build/h5`。`npm run build:static` 会额外复制至 `dist/client`。Sites 完整构建先执行 `npm --prefix .sites-host ci` 安装独立服务端构建依赖，再运行 `npm run build`，同时产出 Worker、静态资源与部署元数据。主前端继续使用同一版本的 DCloud 套件 `3.0.0-5020420260813003` 与 Vite `5.2.8`。

## 导入微信小程序

```sh
npm run build:mp-weixin
```

打开微信开发者工具，选择“导入项目”，目录选择本项目目录；根目录的 `project.config.json` 已将小程序目录指向 `dist/build/mp-weixin/`。也可直接导入生成的 `dist/build/mp-weixin` 目录。

配置中的 `touristappid` 用于游客模式下的本地工程检查。如果开发者工具要求 AppID，请使用自己的测试号或小程序 AppID，并在 `src/manifest.json` 的 `mp-weixin.appid` 和根目录 `project.config.json` 同步修改后重新构建。发布需要自己的微信开发者账号、真实 AppID 和相应平台配置。

开发时可运行 `npm run dev:mp-weixin`，再导入 `dist/dev/mp-weixin` 查看持续编译结果；根目录配置默认指向生产构建目录，开发模式请直接导入 `dist/dev/mp-weixin`。

## 当前功能与数据边界

- 这是可操作的本地演示应用，首次启动包含示例题目、笔记、练习卷和复习记录。
- 支持题目新增、编辑、收藏、筛选、图片记录、回收恢复、复习反馈、复习排期、知识点笔记、关联题目、练习组卷与 DOCX 导出。
- Logo 固定保留在顶部，菜单按钮展开完整学习导航，桌面与手机均可使用；点击遮罩、选择页面或按 Esc 收起。
- 录题支持原作答、字数和标签反馈、自动草稿及恢复。草稿独立保存，正式收录后才更新错题本；保存失败会保留输入。
- 首页“添加错题”支持文字输入与拍照/上传。先保存题干和原图到“待处理”，初始科目、难度、标签、答案与解析留空；图片可在浏览器本地 OCR 后校对，也可先保存原图。首页有待处理入口，错题集按全部、待处理、已整理筛选。
- 录入界面按“录入题目 → 核对入库”两步组织，整理方式放在题目之后。可选“待会整理 / AI 辅助整理”，默认待会整理；AI 路径先成功保存原题，再进入核对页生成。切换选项不发请求，保存失败不启动生成，生成失败仍保留待处理，普通重新打开不会自动调用。
- 电脑端快速收录支持直接拖入本地题图并自动本机 OCR，JPG/PNG/WebP 每张不超过 2MB、同题最多 3 张。识别结果先预览，核对后手动填入题干，保留原图和原先手输文字；拖图不会调用 MiMo。手机保留拍照/上传入口。
- 待处理卡片直接进入整理页。AI 结果核对后可一次“确认并入库”，或先“修改内容”再完成整理；手动表单按题目、分类标签、答案解析排列，其他资料折叠选填。“保存到待处理”回待处理列表，完成后回已整理列表并打开档案，始终保留同一 ID 与原添加时间。提供 16 个预设科目与最多 20 字的自定义科目。
- 待处理题目计入收录总数，但不进入学科、难度、掌握率和复习统计，也不能组卷或安排复习。完成整理需明确科目与难度，可稍后补充答案和解析；需要参考答案才能独立重做。完成整理后再自主安排复习日期。
- 标签库按知识点、题型、学段与方法分组；可搜索全部预设、复用已有标签或自由输入。每题最多 30 个标签、每个最多 32 字；错题库支持关键词与精确标签筛选，详情标签可直接跳转相关题目。
- 复习对照答案后可主动选择下次日期，完成后显示逐题结果，并可重练本轮错题。选择已掌握会清除复习计划。
- “备份与恢复”可导出包含个人资料、题目、笔记、练习卷与复习历史的 JSON，再预览并确认整份恢复。恢复会替换当前学习数据，不会合并。
- 数据通过 `uni` 本地存储保存在当前浏览器或当前小程序中。没有服务端账号、远程题库或云同步；不同浏览器与不同设备之间的数据不互通。
- MiMo 智能整理支持结合原图和校对后的题干生成科目、难度、参考答案、分步解析与标签；仅在点击生成时调用，快速收录不调用模型。需要先部署服务端接口并配置 `MIMO_API_KEY`，没有配置时显示提示。接入方法见 [MiMo 接入说明](docs/MiMo接入.md)。
- 拍照或上传用于记录题图，也可手动输入题干后调用 MiMo。H5 保存本地图片数据，微信小程序保存到本地文件目录。发送给 MiMo 的题图会适当压缩，题目中保存的原图不会被替换。
- 已移除独立的错因字段；旧设备数据、草稿和 JSON 备份仍可读取，其余内容保留。学习报告改为难度分布，原有用户自由标签保留。
- DOCX 导出生成真实的 Word 文件，支持题目文字、PNG/JPEG 题图与可选答案解析附录。某张题图无法读取或格式不支持时，文档会标明需要回应用查看；H5 下载文件，微信通过文档预览打开并允许转存。
- 浏览器清理网站数据或微信清理小程序数据后，本地记录可能丢失。可先导出 JSON 备份和重要练习留存。微信本地题图路径只在原设备有效，JSON 不会打包这些图片文件；跨设备恢复前会提示这一限制。

## 检查

```sh
npm run typecheck
node scripts/verify-export.cjs
npm run build:h5
npm run build:mp-weixin
```

`verify-export.cjs` 检查 H5 与微信导出的含答案、无答案分支，以及 PNG 嵌入和 OOXML 包结构；生成的验证样本位于 `.validation/export-test.docx`。

微信小程序代码可以构建为开发者工具工程，尚未进行微信真机测试。拍照、文件预览、存储容量等设备行为仍需在自己的 AppID 与真机环境中验证。

## 图标

75 种功能图标统一采用 1.75 圆角描边，其中 30 种主要功能图标使用原创双色插画：浅色纸面、深色轮廓和少量暖色细节。其余控件与白色按钮图标沿用 Lucide 的清晰线条；ISC 许可位于 `src/static/icons`。Logo 保持原样。

H5 使用本地 SVG，微信使用相同矢量的内置 base64 数据，不依赖远程图标服务。编辑 `scripts/expressive-icons.cjs` 中的造型或 `scripts/generate-icons.cjs` 中的配色后，运行 `node scripts/generate-icons.cjs` 可重新生成全部 375 个颜色变体。悬停与按压只提供轻微反馈，系统启用“减少动态效果”时关闭图标形变。
