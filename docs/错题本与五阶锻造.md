# 错题本与五阶锻造

产品现名「打铁匠」，标语为「把错题，炼成本领」。统一使用炭黑导航、米白纸面与熔铜橙强调色，标识由锤与砧组成；应用标题、登录入口、导出文案及五阶动画同步更新。原有存储键、接口地址与备份格式保留兼容，避免改名影响已有档案。

本次改版把「管理题目」进一步连接到「记录自己的理解」。书架按题目的实际科目自动归本，未分类题进入收录夹；全部题目、收藏、回收站仍能使用。

每张错题页包含原题、录入时的作答、个人复盘、参考答案、附件和成长足迹。个人复盘分为「当时为什么错」「我现在的理解」「下次提醒自己」，支持分次填写，每项最多 2000 字；个人复盘不会被参考解析或后续练习答案覆盖。

## 五次练习与动画

| 阶段 | 学习任务 | 动画反馈 | 自评通过所需记录 |
| --- | --- | --- | --- |
| 1 识错 · 选材 | 找到具体错处并订正 | 炉火亮起、原铁升温 | 订正、心得、核对确认 |
| 2 重做 · 锻形 | 隐藏答案后独立重做 | 铁匠落锤、火花飞散 | 作答、心得、独立完成确认 |
| 3 讲透 · 淬火 | 解释关键原理及适用条件 | 剑身入水、升起水汽 | 解答、自己的解释、核对确认 |
| 4 迁移 · 磨刃 | 完成另一道同类变式 | 磨石移动、刃面掠光 | 变式题、作答、参考答案／核对依据、心得、确认 |
| 5 回验 · 成锋 | 至少隔一个本机自然日后独立做原题 | 成剑抬起、光芒与星点展示 | 回验作答、心得、确认 |

剑身随阶段改变形态、材质、护手与剑柄。动画是学习反馈；界面同时显示阶段名称、个人复盘和实际练习记录，不将剑或点击次数当成客观理解评分。当前判断方式是学生对照依据自评，没有自动判题或 AI 理解评分。

答错会保存作答和心得，当前阶段继续练习；重试保存复用同一提交标识，不重复增加记录。通过第五阶才会产生新的「已掌握」标记并移出复习计划，题目及整页历史仍保留。已经成锋后可以再次回验；若回验未通过，保留前四阶并重新安排第五阶。

下次日期为可修改的建议，支持清空。第四阶当天不能通过第五阶；页面提供安排回验和跳过入口，不会消耗这次未提交的任务。未整理题不能开始锻造，缺少参考答案的题需要先补齐。

## 历史档案与验证

旧题目、旧的掌握标记、旧复习记录继续保留。旧记录不会被推断成已完成五阶，原有掌握标记与五阶记录并列说明。新增字段为 `Question.reflection` 和 `ReviewRecord.forge`，仍兼容 1 版档案；本地保存、云端整份档案传输和 JSON 备份保留这些字段。备份恢复会校验字段、跳阶记录、迁移依据及回验日期。

`npm run verify:forge` 覆盖阶段规则、重复提交、历史兼容、保存失败重试和备份往返。浏览器检查使用独立测试档案，不修改用户浏览器数据。已检查桌面及 390px、320px 布局。微信小程序可构建；动画的微信真机表现仍需在开发者工具／手机上检查。

涉及的核心实现：`src/domain/forge.ts`、`NotebookShelf.vue`、`QuestionReflection.vue`、`ForgeProgress.vue`、`ReviewSession.vue`。
