# 在这台 Windows 电脑演示

本地运行完整 H5 页面、Go 服务和 SQLite 题库，浏览器打开 `http://127.0.0.1:8080/`。无需手机、热点或公网隧道；AI 识题仍需要网络连接 DeepSeek。

准备好的 `.local-demo/` 包含 `shiti-server.exe`、`public/`、`data/` 和此 Windows 用户加密的 `runtime-env.clixml`。私密配置、题库、图片、程序和运行日志均不进入 Git。首次准备时可从 VPS 导入题库及图片副本，此后两份题库分别保存，不会自动同步。

启动：双击交付的“启动本地演示”入口，或在工程根目录执行：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File scripts/start-local-demo.ps1
```

启动程序会在后台运行并打开浏览器。已启动时再次执行会打开现有实例。演示使用原题库对应的账号密码；不会因切换到 localhost 自动继承公网网站的登录状态。

停止：双击“停止本地演示”入口，或执行：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File scripts/stop-local-demo.ps1
```

关闭浏览器不会停止服务；停止服务也不会删除题目。配置只可由同一电脑的同一 Windows 用户解密，在其他电脑演示需重新配置。若无法启动，查看 `.local-demo/stderr.log`；脚本不会结束占用端口的其他程序，也不会开放防火墙或监听局域网。

从源码准备时，先构建 H5 和 Windows 后端，再复制到上述目录。服务端配置通过标准输入交给 `scripts/configure-local-demo.ps1`，该脚本只保存 Windows DPAPI 加密配置，不在命令参数、网页或日志中输出密钥。
