# 自建错题本

更新日期：2026-11-05。

## 书架与归属

错题本是独立保存的 `Notebook`，可以先建空本，再收录题目。书架的主要操作为“建一个错题本”；支持填写名称、选择学习方向和封面，后续可改名、换封面。

题目通过 `notebookId` 归入一本错题本，`subject` 仍表示题目学科，两者独立。自建本可以包含不同科目的题，改题目科目不会把它移出自建本。错题本的默认科目只用于收录、整理时预填建议，不是成员限制，也不改变题目的判题或组卷学科规则。

进入某本后收录，默认归入当前本；全局收录可以选择目标本，也可以选择按科目自动归档。编辑题目时可以重新选择所属本，批量移动使用同一套归属校验。

## 18 种封面

| 学习方向 | 数量 | 封面 |
| --- | --- | --- |
| K12 | 6 | 数学、英语、语文、物理、化学、科学综合 |
| 计算机学习 | 5 | 编程开发、数据结构与算法、数据库、计算机网络、操作系统 |
| 考公 | 3 | 行测、申论、公共基础 |
| 通用 | 4 | 森林手记、亚麻原色、午夜星图、陶色随记 |

封面是本地代码绘制的视觉样式，定义在 `src/domain/notebooks.ts` 的 `NOTEBOOK_COVERS`。封面不限制题型、学科或学习对象；使用者可以按自己的学习项目命名。

## 迁移与持久化

- 旧数据只有学科分组、没有真实错题本时，按题目科目创建确定标识的默认本，并为每道题写入归属。重复迁移不会重复建本。
- 默认“待分类收录夹”中的自动归档题，整理完成并选择科目后，转入对应科目默认本；明确选择的自建本不会自动迁移。
- 空本、名称、学习方向、封面、默认科目及题目归属都会保存，刷新后仍在。删除题目不会删除空下来的本子。
- 删除错题本有保护规则：只有本内没有任何题目（包括回收站中的题目）时才允许删除；有题目时必须先移动或清空，避免题目失去归属。
- 移动题目只修改归属和更新时间，不修改原题、作答、复盘或测试记录，不重置锻造进度。
- 修改默认本的名称或封面后，它成为用户明确管理的本子，不再执行待分类本的自动迁移。

## 备份与兼容

JSON 备份保持 `schemaVersion: 1`，新增 `data.notebooks` 和题目的 `notebookId`。导出包括空本与回收站题目的本子归属，恢复时校验本子标识、封面、字段与题目引用。

旧备份没有 `notebooks` 或题目没有 `notebookId` 时，会自动迁移；新数据显式引用不存在的本子、封面无效或标识重复时，整份校验失败，不会悄悄丢掉记录。`BackupCounts` 新增 `notebooks`，恢复预览会显示错题本数量。数据上限为 2000 本。

## 验证

`npm run verify:notebooks` 覆盖空本持久化、重复迁移、旧备份兼容、自建归属稳定、修改封面、移动不丢测试进度、错误赋值和批量创建的原子校验。

五次明确测试通过完成锻造的规则继续生效，详见 [测试与锻造](测试与锻造.md) 与 [产品逻辑设计](产品逻辑设计.md)。
