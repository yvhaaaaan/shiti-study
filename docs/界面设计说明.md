# 打铁匠界面设计

## 工作区重设计

保留科目笔记本封面。其余界面使用 `src/workspace.css` 统一内容面板、导航、编辑器和测试页面的排版；首页改为今日测试、学习积累、收录工具和最近记录。题目详情提供题目与解析、我的复盘、练习记录三个页签，以 `v-show` 保留切换时的未保存复盘草稿。知识笔记在未选中内容时使用完整网格，选中后再显示阅读区。练习卷移除装饰封面，保留科目与题量信息。

验证覆盖六个主页面在桌面和 390 / 320 像素宽度下的布局，详情页签、复盘草稿保留、答案展开，以及原有测试与锻造流程。浏览器脚本为 `.validation/workspace-qa.cjs`。

本轮保留卡片式错题本，重新组织书架、导航和题目浏览。五阶锻造与个人复盘的数据规则不变。

## 参考与取舍

- Goodnotes：https://support.goodnotes.com/hc/en-us/articles/7378598719759-Get-Started-With-Goodnotes-for-Android-Windows-and-Web 。参考其笔记本封面与资料库的组织方式；本应用按科目自动归档。
- Craft：https://www.craft.do/organize 。参考内容分组与层级组织，避免把所有功能放进同一张卡片。
- Things：https://culturedcode.com/things/ 。参考安静的导航与明确的主要操作。

以上为设计参考，未复制品牌、图片或产品代码。封面由本项目 CSS 和文字构成。

## 本轮落地

工作区使用浅纸色，导航使用浅灰绿，主操作使用深绿。科目封面分别使用松绿、赭黄、蓝灰、陶红与橄榄色，以书脊、封签、弹力带和抽象科目图形形成识别。

封面下方显示笔记本名称、复盘数和完成五阶的题目数。继续复盘入口按题目修改时间选取最近整理的题目，不表示最后阅读记录。新增入口复用既有错题收录流程。

桌面使用三列书架，小屏使用两列。动效仅用于悬停反馈，并尊重系统减少动画设置。

## 验证

通过浏览器检查卡片打开、题目详情、继续复盘、全部题目、新增收录以及 1440 / 1024 / 768 / 390 / 320 宽度下无横向溢出。通过 Vue 类型检查和 H5 构建。
