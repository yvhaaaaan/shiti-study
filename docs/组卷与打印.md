# 组卷与打印

底部第四项「组卷」用于挑选错题、调整题量和顺序、保存试卷、预览和打印；第五项「练习」用于在线测试与锻造。侧边栏从左上角菜单打开。

组卷页不再提供在线练习按钮。每份试卷可以直接打开打印预览，预览采用 A4 纵向排版，支持紧凑、标准、宽松三档作答留白，默认不附答案，可选择卷末单独附参考答案与解析。

打印内容保留原题文字、公式与题图，按组卷顺序编号，不包含学生原作答、错因、心得或学习状态。缺少参考答案不会删掉试题，而在答案页显示待补充。原卷中删除或未整理的题目会在预览外明确提示不可用题数。

网页通过独立预览文档调用浏览器打印，可在系统对话框选择打印机或存为 PDF，应用导航和操作栏不会打印。题图加载失败会阻止打印并提示重试。Word 导出继续保留；微信小程序端提供内容预览并导出 Word，再从文档打开界面处理打印。

已验证：试题顺序、公式、题图、留白变化、单独答案页、缺答案题保留、个人学习内容排除、打印调用、手机预览、Word 导出及双端构建。测试不会向真实打印机发送文档。
