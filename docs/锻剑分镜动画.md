# 二维锻剑动画

当前采用前端绘制的分层 SVG 与 CSS 动作，不依赖生图接口。由子智能体实现绘画与动作，主智能体负责接入、浏览器验证和导出预览。

## 画面与节奏

背景、铁匠躯干、举锤手臂、铁砧、剑坯、水桶、磨轮、成剑共八个 SVG 素材位于 `src/static/forge/`，总计约 11.5 KB。深青工坊与琥珀炉火形成冷暖对比。

五次测试通过分别展示炉火升温、举锤锻形、入水淬火、磨轮开刃、成剑流光。落锤有蓄力、快速击打、回弹、震动与方向性火花；淬火有水波、蒸汽与水滴；成剑有光晕与沿剑刃移动的高光。

播放约 4.2 秒后停在完成姿态，支持暂停、继续、重播，响应系统减少动画设置，并清理卸载后的定时器。完整画面用于测试反馈，列表保留紧凑进度条。五次答对的业务规则保持原样。

## 文件

- `src/components/ForgeScene.vue`：分层画面与播放控制。
- `src/components/ForgeProgress.vue`：完整场景容器与五阶段进度条。
- `.validation/cinematic-forge-qa.cjs`：实际五阶段播放、暂停继续、手机宽度、减少动画设置与自动停帧检查。
- `../交付文件/打铁匠_二维锻造动画预览.gif`：来自应用真实播放的落锤片段。

## 生成尝试记录

之前已尝试内置 imagegen：首次网络错误，后续生成请求被服务以 violence 分类拦截，包括用户指定的动画电影画风。因此当前没有使用或声称使用 AI 生成的图片；没有转用其他智能体绕过同一服务的审核。
